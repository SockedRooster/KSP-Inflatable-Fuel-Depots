# InflataDepot 1.0.3 - VAB Deflate

Close KSP and replace GameData/InflataDepot with this version. Keep B9 Part
Switch and ModuleManager installed. Both the updated configs and DLL are needed.

In the VAB/SPH, right-click the depot and choose Inflate Fuel Depot. The same
stock animation button then becomes Deflate Fuel Depot. Repeat as needed.
Station Grey and Original remain available. Tanks remain empty at launch.
Flight still uses custom controls that block deflation while fuel is present.

Validation: rebuilt against installed KSP assemblies; existing asset checks
passed for all three sizes; editor config checks passed; models, textures
and colour variants unchanged. ZIP integrity checked. No game DLLs bundled.

In-game verification pending: repeatedly inflate/deflate each size in VAB/SPH,
check symmetry copies and craft save/reload, then launch and check that a tank
