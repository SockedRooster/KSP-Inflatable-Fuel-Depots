# InflataDepot 1.0.5 - No staging

Close KSP and replace the entire GameData/InflataDepot folder with this version.
Keep ModuleManager and B9 Part Switch installed.

The depot docking ports have staging disabled permanently, with staging toggles
hidden in the VAB/SPH and flight. Previously saved staging-enabled ports are
reset using KSP's stock staging API. Manual docking/undocking/decoupling controls
remain available. Always-on crossfeed, VAB Inflate/Deflate and both colour
variants remain included. Tanks still launch empty and require deployment to fill.

Validation: compiled against installed KSP assemblies; all existing asset tests
passed; staging defaults verified in all three configs; models/textures/colour
patch unchanged; archives checked. No game libraries bundled.
In-game testing completed by the maintainer for v1.0.5. The offline checks above
were also completed; no KSP/Unity game libraries are bundled.
