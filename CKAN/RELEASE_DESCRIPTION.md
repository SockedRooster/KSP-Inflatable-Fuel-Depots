# InflataDepot (SockedRooster)

Launch compact pancake fuel depots and inflate them into cylindrical storage tanks. Three part sizes (1.25 m, 2.5 m, 3.75 m), a single bottom Clamp-O-Tron-compatible port, and selectable LF/OX or LF-only storage using B9 Part Switch.

**Collision-test preview:** inflatable body collider is now animated with the tank. This physics change still requires player testing before public stable release.

Dependencies: B9 Part Switch + ModuleManager.
