# InflataDepot 1.0.2 - Station Grey

Close KSP and replace GameData/InflataDepot with the folder from this ZIP.
Keep ModuleManager and B9 Part Switch installed.

Right-click any depot in the VAB or SPH and use the stock variant selector:
Original or Station Grey. The colour choice is separate from Fuel Configuration.
The 1.0.1 Inflate/Deflate editor controls remain included. Tanks launch empty.
Station Grey matches the station modules' steel palette while preserving the
original fabric texture detail, gold straps, nameplates and docking base.

Validation: existing asset checks, patch structure/material targets, unchanged
plugin/models/textures/fuel settings, ZIP integrity and dependency contents.
No in-game testing performed. Check colour switching in both directions on
all sizes, symmetry copies, save/reload, and folded/deployed states in KSP.
